# 🏴‍☠️ YaSave — Yandex Music Downloader

![YaSave Cover](assets/cover.jpg)

**YaSave** — современное, стильное приложение для скачивания музыки с **Яндекс Музыки** с эстетикой **Liquid Glass (Glassmorphism)**, поддержкой тёмной и светлой темы, процентным прогресс-баром, официальной авторизацией по коду устройства и поиском треков без цензуры (Explicit / Uncensored) из альтернативных источников.

Разработано под **Android (сборка APK)**, а также поддерживает запуск на Windows/macOS/Linux.

---

## Ключевые возможности

1. **Умный парсинг ссылок**:
   - Поддерживает ссылки на треки (`https://music.yandex.ru/album/.../track/...`, `/track/...`, короткие ссылки и прямые ID).
   - Очищает мусорные GET-параметры (`?utm_medium=...`).
2. **Полные метаданные и обложка (ID3v2)**:
   - Вшивает в скачанный `.mp3` файл:
     - Обложку альбома в максимальном разрешении (1000x1000) через тег `APIC`.
     - Название трека (`TIT2`).
     - Исполнителя / авторов (`TPE1`).
     - Название альбома (`TALB`).
     - Год релиза (`TDRC`).
   - Файлы отображаются с обложкой и тегами в любом плеере (Samsung Music, Apple Music, VLC, Poweramp и т.д.).
3. **Процентный индикатор загрузки**:
   - Заполняющаяся неоновая полоска прогресса (0% — 100%).
   - Отображение скачанных МБ / общего размера, скорости скачивания и статуса этапов в реальном времени.
4. **Liquid Glass дизайн (Тёмная и Светлая темы)**:
   - Трендовый стеклянный дизайн с эффектом матового стекла, мягкими неоновыми акцентами Яндекс-желтого и градиентными бликами.
   - Переключение между глубокой тёмной темой (Obsidian Glass) и воздушной светлой темой (Frosted Milk Glass) по одной кнопке.
5. **Удобная авторизация (2 режима)**:
   - **Автоматически через `ya.ru/device`**: приложение выдаёт одноразовый код, вы подтверждаете его в браузере или по клику — и токен моментально подтягивается сам!
   - **Вручную**: вставка известного OAuth токена с валидацией аккаунта и статуса Яндекс Плюс.
   - Токен безопасно сохраняется в конфигурации и не требует повторного ввода.
6. **Поиск без цензуры (Альтернативные источники)**:
   - Если в Яндекс Музыке трек с цензурой или недоступен, нажмите кнопку **"Найти без цензуры"**.
   - Поиск по YouTube / SoundCloud / Web с выдачей нескольких вариантов.
   - **Предпрослушивание аудио** прямо в приложении перед скачиванием!
   - Скачанный альтернативный аудиопоток автоматически упаковывается с оригинальной обложкой, названием и автором из Яндекс Музыки.

## Архитектура проекта

```text
YaSave/
├── assets/
│   ├── cover.jpg               # Сгенерированная стильная обложка с кибер-пиратом
│   └── icon.png                # Иконка приложения для Android launcher (1024x1024)
├── core/
│   ├── config.py               # Сохранение токена, тем и настроек
│   ├── storage.py              # Автоматическое определение папки Download (Android/PC)
│   ├── metadata.py             # Вшивание ID3 тегов и обложки (mutagen)
│   ├── auth.py                 # OAuth Device Flow (ya.ru/device) и проверка токена
│   ├── yandex_api.py           # Парсинг ссылок, получение инфо и потоковая загрузка
│   └── alt_sources.py          # Поиск без цензуры (yt-dlp), стриминг превью и конвертация
├── ui/
│   ├── theme.py                # Движок тем Liquid Glass (Dark / Light)
│   ├── components.py           # GlassCard, GlassButton, GlassProgressBar, GlassTextInput
│   └── modals.py               # Модальные окна авторизации и выбора источников
├── .github/workflows/
│   └── build_apk.yml           # CI/CD автоматическая сборка APK на GitHub Actions
├── main.py                     # Главная точка входа приложения
├── Saver.py                    # Быстрый запуск приложения
├── buildozer.spec              # Конфигурация сборки APK под Android (API 34)
├── BUILD_GUIDE.md              # Подробная инструкция по сборке APK
└── requirements.txt            # Зависимости Python
```

## Локальный запуск на компьютере (Windows / macOS / Linux)

Для проверки и работы на ПК:

```bash
# Активация виртуального окружения (если используется)
.\.venv\Scripts\activate

# Запуск приложения
python main.py
```
*(Также можно запустить `python Saver.py`)*

## Сборка APK для Android

Самый удобный способ — загрузить проект на GitHub и запустить **GitHub Actions** (готовый `.apk` соберется на сервере Ubuntu и будет доступен для скачивания в 1 клик).

Подробная инструкция со всеми вариантами описана в файле [BUILD_GUIDE.md](file:///c:/Users/Van4ous/YaSave/BUILD_GUIDE.md).
