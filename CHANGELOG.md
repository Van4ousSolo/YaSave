# История изменений

## 2.1

### Плеер
- Плеер в шторке уведомлений и на экране блокировки: обложка, название, исполнитель, назад / пауза / вперёд / закрыть. Музыка продолжает играть в фоне (foreground-сервис с типом mediaPlayback).
- Полоска времени в уведомлении: системная (через MediaSession: позиция, скорость, перемотка) или своя полоска для оболочек, которые системную не рисуют (vivo / Origin OS). Выбирается в Настройках, две полоски одновременно не показываются. Перемотка в шторке двигает плеер в приложении.
- Тонкие контурные иконки в уведомлении и белая монохромная нота вместо цветного значка.
- Мини-плеер над меню с кнопкой «Назад» (после 3 секунд или на первом треке перезапускает трек), полноэкранный плеер, очередь из результатов поиска или Истории, автопереход к следующему треку.
- Исправлена ошибка `ClassNotFoundException` у нативного плеера: Java-классы теперь загружаются в главном потоке.

### Скачивание и качество
- Выбирается лучший поток из тех, что вернул Яндекс (FLAC без потерь, MP3 320, ниже как запасной вариант). FLAC / M4A / MP3 сохраняются с тегами, реальный битрейт проверяется по сохранённому файлу.
- Честное сообщение о качестве и кнопка «Проверить доступное качество» в Настройках: все варианты от Яндекса, статус Плюса, каким клиентом выдан токен.

### Поиск
- У каждого источника виден статус: число результатов, «ничего не найдено» или ошибка с причиной. SoundCloud через API v2 с автоматическим получением client_id, треки только с DRM скрыты.
- Spotify Match без ключей пользователя, с запасными каталогами Deezer и iTunes.
- Диагностика источников в Настройках.

### Интерфейс
- Стеклянные поверхности Liquid Glass. Фон с аурами возвращён из 2.0 (свечение акцентного цвета сверху справа, фиолетовое и синее внизу), теперь без покадрового размытия.
- Мини-плеер и меню объединены в одну закреплённую панель, контент под неё не уходит.
- Экран «Чтобы плеер работал в фоне»: уведомления, батарея, автозапуск на vivo, живой статус.
- Диагностика плеера с журналом прямо в приложении (скопировать, сохранить, поделиться).

### Сборка
- CI проверяет готовый APK: нативные классы в dex, разрешения и сервис в манифесте, ресурсы, иконки уведомления.
