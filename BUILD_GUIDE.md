# 📱 Пошаговое руководство по сборке YaSave (Для новичков)

В проекте всё уже настроено и подготовлено под ключ. Вам не нужно устанавливать тяжелые Linux-утилиты или настраивать Android SDK на компьютере вручную — облачные серверы GitHub сделают это бесплатно и автоматически!

---

## 🚀 Способ 1: Сборка Android APK через GitHub Actions (Самый простой!)

### Шаг 1: Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в свой аккаунт (или зарегистрируйтесь).
2. Нажмите зеленую кнопку **«New»** (или значок `+` в правом верхнем углу ➔ **«New repository»**).
3. В поле **Repository name** напишите: `YaSave`.
4. Выберите **Private** (приватный, виден только вам) или **Public** (публичный).
5. ⚠️ **Важно:** Галочки *«Add a README file»*, *«Add .gitignore»* и *«Choose a license»* **НЕ ставьте** (они уже созданы в проекте).
6. Нажмите **«Create repository»**.

---

### Шаг 2: Отправьте проект на GitHub
После создания репозитория скопируйте его ссылку (она будет вида `https://github.com/ВАШ_ЛОГИН/YaSave.git`).

Откройте терминал (PowerShell или Git Bash) в папке `C:\Users\Van4ous\YaSave` и выполните всего 2 команды:

```powershell
git remote add origin https://github.com/ВАШ_ЛОГИН/YaSave.git
git push -u origin main
```
*(При первом пуше Git откроет окно браузера с кнопкой «Authorize Git Credential Manager» — просто подтвердите вход).*

---

### Шаг 3: Автоматическая сборка в облаке
1. Откройте ваш репозиторий на GitHub в браузере.
2. В верхнем меню перейдите во вкладку **«Actions»**.
3. Вы увидите запущенную сборку **«Build Android APK»** (желтый крутящийся индикатор).
4. Облачный сервер GitHub сам установит Java, Python, Android NDK и соберет `.apk`.
5. Это займет примерно **6–8 минут**. Когда сборка завершится, появится зеленая галочка **✅**.

---

### Шаг 4: Скачивание APK на телефон
1. Нажмите на название завершенной сборки (зеленая строчка с коммитом).
2. Прокрутите страницу в самый низ до раздела **Artifacts** (Артефакты).
3. Нажмите на **`YaSave-Debug-APK`** — начнется скачивание архива `.zip`.
4. Распакуйте архив — внутри будет лежать готовый файл **`YaSave-2.0.0-arm64-v8a-debug.apk`**.
5. Отправьте файл на телефон (через Telegram «Избранное», провод или облако) и нажмите «Установить»!

---

## 💻 Способ 2: Сборка EXE для Windows (ПК)

Если вам нужен автономный `.exe` файл, который запускается на любом Windows-компьютере в один клик без терминалов:

1. В папке проекта дважды кликните по файлу **`build_windows.bat`**.
2. Дождитесь завершения процесса (1–2 минуты).
3. Готовая программа появится в папке:
   ```
   dist\YaSave\YaSave.exe
   ```
4. Этот `.exe` открывает нативное красивое окно с Liquid Glass интерфейсом.
